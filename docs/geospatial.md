# Geospatial Works

My geospatial work uses GIS and spatial statistics to show where health risks and gaps in access cluster across Pima County and Tucson, Arizona. Each project below is an interactive ArcGIS StoryMap that combines maps, analysis, and narrative. Use **Quick preview** to look inside a story without leaving this page, or open the full story map for the complete analysis.
